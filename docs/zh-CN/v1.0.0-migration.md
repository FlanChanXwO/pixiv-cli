# 迁移到 Pixiv CLI v1.0.0

[English](../en/v1.0.0-migration.md) | 简体中文 | [文档索引](../index-zh-CN.md)

v1.0.0 是公开 Pixiv Go SDK 的最后一次破坏性重写。本指南覆盖 v0.x 消费者迁移到 v1 的所有变化。

## SDK 包布局

旧公开包 `pixiv` 已移除。v1 公开面为：

```text
github.com/FlanChanXwO/pixiv-cli/sdk
github.com/FlanChanXwO/pixiv-cli/sdk/pixiv
github.com/FlanChanXwO/pixiv-cli/sdk/fanbox
```

一次构建只能选择根 module 的一个版本，因此消费者从 v0 `/pixiv` 切换到 v1 `/sdk/pixiv` 需一次完成：

```go
// v0
import "github.com/FlanChanXwO/pixiv-cli/pixiv"
client, err := pixiv.NewClient(...)

// v1
import "github.com/FlanChanXwO/pixiv-cli/sdk/pixiv"
client, creds, err := pixiv.Open(ctx, refreshToken) // 执行 OAuth rotation
```

旧 `pixiv` 包仍在其不可变的 v0 tag 可取；v1 不保留兼容包。

## 认证

- `pixiv.Open(ctx, refreshToken)` 刷新一次并返回一个只持有 access token 的 `Client`，以及轮换后的 `Credentials`。在发起内容请求前必须持久化轮换后的 refresh token；Client 不会自行刷新。
- `pixiv.New(accessToken)` 以静态 token 构建一个 client，无网络 I/O，也不推断 user ID。
- 所有内容操作都要求有效 access token。没有匿名或 Web fallback；`web_fallback_enabled` 与 `PIXIV_WEB_FALLBACK_ENABLED` 已移除，若仍存在则返回 `removed_setting`。
- FANBOX 是独立产品（`sdk/fanbox`），使用自己的 session credential；Pixiv refresh token 与 FANBOX session 互不转换或 fallback。

## 本地状态

认证从 `~/.pixiv-cli/auth.json` 迁移到 `~/.pixiv-cli/pixiv-cli.db`（SQLite）。新 CLI 不会自动读取或迁移旧 `auth.json`。切换版本前，先用旧 CLI 运行 `pixiv auth export --all --output <private bundle>`，再用新 CLI 运行 `pixiv auth import < bundle.json`。默认账号存储在 `config.toml` 的 `[pixiv.auth].default_user_id` 与 `[fanbox.auth].default_user_id` 下；未设置时使用 sort order 最小的账号。

账号池成员资格也移出 TOML。支持的 `[account_pool]` 键只有 `enabled` 与 `strategy`；每个账号的 `schedulable`、freeze 与 round-robin marker 状态存储在 `pixiv-cli.db` 中。旧 `account_pool.accounts` 键不会自动迁移。若它仍然存在，运行时配置返回 `removed_setting`；用 `pixiv config unset account_pool_accounts` 显式清理。历史的 `data/account-pool.json` 调度器不会被自动读取、迁移或删除；确认不再需要后可手工移除。

## 命令与 MCP 面

- `version` 子命令（含其 `--json` 形式与 build metadata）已移除。使用 `pixiv --version`；它精确输出一行 `pixiv <version>`。解析过旧 JSON 输出的脚本须迁移到该 root flag。
- `pixiv mcp` 运行 Pixiv MCP server；`pixiv fanbox mcp` 运行独立的 FANBOX MCP server。它们从不共享 client、cursor 或 credential。
- `pixiv fanbox` 新增 FANBOX 命令：`auth import`、`auth list`、`auth use`、`auth remove`、`auth status`、`creators`、`posts`、`tags`、`home`、`supporting`、`download` 与 `mcp`。
- `pixiv fanbox auth import --from-browser BROWSER` 在在线校验后从浏览器（Chrome/Edge/Firefox/Safari）读取 FANBOX session。

## Model 与输出变化

公开运行时 model 是 v1 的 `sdk/pixiv` 与 `sdk/fanbox` 类型（`Artwork`、`Novel`、`User`、`Post`...）。CLI 与 MCP 的结构化输出现在使用显式的逐字段 DTO（以及 entity 流的 pipeline `Record` 值），带稳定的 snake_case key 与规范化的顶层 `id`（string）、`type` 与 `url`（适用 record protocol 处）。运行时 model 不得直接 JSON marshal。媒体仍通过 `sdk.Resource`（可用 URL 加 opaque ref）提供给程序化 SDK 调用方，而 `sdk.ResourceDTO` 只暴露 opaque `ref` 与可选的 `requires_credentials`；诸如 `OriginalURL` 的原始 upstream URL 字段、请求头与过期 metadata 不会穿越 CLI/MCP 输出边界。
