# v0.3.0 — 2026-07-15

## Breaking changes

- The public SDK moved to its stable import path, and its artwork recommendations, artwork detail, and raw refresh-token methods now have explicit parameters and return types. ([#7](https://github.com/FlanChanXwO/pixiv-cli/pull/7))

## Added

- `pixiv search` and the SDK can filter illustrations by rating, artwork type, and AI-generated mode. ([#3](https://github.com/FlanChanXwO/pixiv-cli/pull/3))

## Fixed

- Update checks identify their own GitHub requests, cursors decode reliably, and browser login reports its result instead of failing silently. ([#4](https://github.com/FlanChanXwO/pixiv-cli/pull/4), [#6](https://github.com/FlanChanXwO/pixiv-cli/pull/6))

**Full Changelog**: [v0.2.0...v0.3.0](https://github.com/FlanChanXwO/pixiv-cli/compare/v0.2.0...v0.3.0)
