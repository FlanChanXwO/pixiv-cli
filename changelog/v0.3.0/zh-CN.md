# v0.3.0 — 2026-07-15

## 破坏性变更

- 公开 SDK 迁移到稳定导入路径；作品推荐、作品详情和原始 refresh token 方法现在有明确的参数和返回类型。（[#7](https://github.com/FlanChanXwO/pixiv-cli/pull/7)）

## 新增

- `pixiv search` 与 SDK 可按分级、作品类型和 AI 生成模式筛选插画。（[#3](https://github.com/FlanChanXwO/pixiv-cli/pull/3)）

## 修复

- 更新检查会正确标识自己的 GitHub 请求，cursor 解码更可靠，浏览器登录会显示结果而不是静默失败。（[#4](https://github.com/FlanChanXwO/pixiv-cli/pull/4), [#6](https://github.com/FlanChanXwO/pixiv-cli/pull/6)）
