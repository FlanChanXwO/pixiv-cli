# v1.3.0 — 2026-10-31

## Breaking changes

- **Go SDK:** Replace removed `XxxDTO` types and `ToXxxDTO` converters with the public entity models, which now serialize directly. Replace `AddBookmark` / `RemoveBookmark` with `AddArtworkBookmark` / `RemoveArtworkBookmark`; `SetAIArtworkVisibility` is removed. Replace `Artwork.Kind` / `RawKind` and `ArtworkKind` with `Artwork.ContentType` and `ContentType` (`illust`, `manga`, `ugoira`); unknown upstream values are preserved. Empty tag translations and absent profile/cover images are omitted from JSON. ([#170](https://github.com/FlanChanXwO/pixiv-cli/pull/170), [#271](https://github.com/FlanChanXwO/pixiv-cli/pull/271))
- **CLI JSON and NDJSON:** Content lists use `{records, pagination}` with string IDs. Artwork records use `type:"artwork"`; select subtypes through `content_type`. `recommended --type all` groups results into `artworks`, `novels`, and `users`. Pipeline diagnostics drop `kind:"record_error"`. Update scripts consuming these outputs. ([#271](https://github.com/FlanChanXwO/pixiv-cli/pull/271))
- **MCP and FANBOX selectors:** MCP entity selectors change from `kind` to `type`. `pixiv_recommended` accepts `type=all|artwork|novel|user`, with artwork subtypes selected through `content_type=all|illust|manga`, and returns entity partitions. Change `fanbox_creators.kind` to `relation` and CLI `fanbox creators --kind` to `--relation`. ([#271](https://github.com/FlanChanXwO/pixiv-cli/pull/271))
- **Account JSON:** Auth summaries remove `has_token`, `premium_status_checked_at`, `warning`, and `eligible`; account-list and bundle-import results remove redundant `default_user_id`. An empty `auth list --json` returns `"accounts":[]`. Update consumers relying on these fields. ([#271](https://github.com/FlanChanXwO/pixiv-cli/pull/271))
- **Gallery settings:** Remove `mcp_gallery_cache_ttl` and `mcp_gallery_concurrency`. Cache TTL is fixed at 15 minutes; metadata and image read concurrency are each fixed at 4. Remove obsolete settings from `config.toml`; leftover undeclared keys are ignored when loading configuration. ([#168](https://github.com/FlanChanXwO/pixiv-cli/pull/168), [#185](https://github.com/FlanChanXwO/pixiv-cli/pull/185))
- Remove the pointless `pixiv --licenses` command and bundled third-party license notices. Remove invocations of this flag from scripts. ([#234](https://github.com/FlanChanXwO/pixiv-cli/pull/234))

## Added

- Add `pixiv whoami [--json]` to show the current local Pixiv account and cached Premium status without network access or token rotation. JSON output matches an `auth list --json` account entry. ([#260](https://github.com/FlanChanXwO/pixiv-cli/pull/260))
- Add the HTTP MCP `pixiv_show_artwork` tool for displaying a single artwork. The Gallery adapts to phones and embedded panels and adds cube-style page turns. ([#167](https://github.com/FlanChanXwO/pixiv-cli/pull/167))

## Changed

- Unify terminal output with readable account identities, status labels, single-line lists, and detail cards. Empty results print `No results.` to stderr and exit successfully. `fanbox download` keeps stdout empty on success. Scripts parsing text should use `--json` or `--ndjson` where supported, applying the migration changes above. ([#269](https://github.com/FlanChanXwO/pixiv-cli/pull/269), [#270](https://github.com/FlanChanXwO/pixiv-cli/pull/270))
- Compact stderr logs with timestamps, operations, levels, and source locations. JSON logs include command-failure records; debug logs add SDK error origins and safe network details, including OAuth token-exchange failures. Default text logging keeps one error line. ([#258](https://github.com/FlanChanXwO/pixiv-cli/pull/258), [#261](https://github.com/FlanChanXwO/pixiv-cli/pull/261))

## Fixed

- Preserve MCP artwork filters when a bookmark strategy is explicitly selected without bookmark bounds. Apply bookmark bounds and artwork filters together before pagination. CLI and MCP `best_effort` searches report `partial` even when candidates are empty or exhausted. ([#165](https://github.com/FlanChanXwO/pixiv-cli/pull/165))
- Treat early downstream pipe closure as success across automatically selected NDJSON commands, including series, bookmarks, comments, and reverse search. ([#246](https://github.com/FlanChanXwO/pixiv-cli/pull/246))
- Escape upstream titles, names, comments, and tags in terminal output. Explain authentication, argument, HTTP, timeout, and cancellation failures with a next step; validate local enum arguments before opening an account. FANBOX creator and post commands report output-write failures. ([#268](https://github.com/FlanChanXwO/pixiv-cli/pull/268))
